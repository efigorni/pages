# הסכמה של lesson.yaml

קובץ אחד לכל שיעור: `lesson-lab/lessons/<slug>/lesson.yaml`. תוכן בלבד — בלי HTML ובלי עיצוב. המפתחות באנגלית, הערכים בעברית. מה כותבים בכל שדה — `style-guide.md`; כאן — הצורה. `validate.py` בודק הכול.

## כללי YAML (נשברים בלי זה)

- **טקסט עברי — רק בסגנון בלוק**: ערך אחרי `key: ` או אחרי `- `. אף פעם לא בתוך `[ … ]` או `{ … }` — סימן שאלה או פסיק בתוכם שוברים את הקובץ ("מה הקשר?"). רשימות כותבים בשורות, `- ערך` בכל שורה. `[ … ]` / `{ … }` מותרים רק למספרים ולמזהים (`{use: heart, x: 200, y: 150}`).
- ערך שמתחיל ב-`**`, או שיש בו `: ` (נקודתיים ורווח) או ` #` — כותבים כבלוק:
  ```yaml
  - p: >-
      **לפני השיעור:** פתחי את המצגת. על הלוח: שאלה אחת.
  ```
  `>-` מחבר שורות לפסקה אחת; `|` שומר על שורות (שבירת שורה במערך).
- זמן בסרטון במירכאות: `pause: "1:05"` (בלי מירכאות YAML קורא 65).
- הסימון היחיד בתוך טקסט: `**מודגש**` ושבירות שורה. בלי HTML.
- `say` / `ask`: בלי מירכאות מסביב — המערך מוסיף ״…״ בעצמו.

## שדות השיעור

מעתיקים מ-`lesson-lab/docs/lessons.json` (לפי ה-slug) — אותם שמות ואותם ערכים:

| שדה | סוג | חובה | הערה |
|---|---|---|---|
| `slug` | מחרוזת | – | אם קיים — זהה לשם התיקייה |
| `title` | מחרוזת | ✓ | שם השיעור |
| `grade` | 6–9 | ✓ | |
| `grades_served` | רשימת מספרים | – | שיעור שמשרת כמה שכבות |
| `month` | מחרוזת | ✓ | חודש, או טווח עם מקף: `ינואר–פברואר` |
| `section` | מחרוזת | ✓ | הפרק כפי שבמלאי (החודש בסוגריים יורד בתצוגה) |
| `unit` · `unit_order` · `unit_size` | מחרוזת · מספר · מספר | ✓ · – · – | היחידה, מספר השיעור בה, כמה שיעורים בה |
| `src_text` | נתיב | ✓ | יחסית ל-`lesson-lab/`, למשל `sources/text/7/Makom_Baolam.md` |
| `src_url` | כתובת | – | המצגת המקורית (קישור בתחתית המערך) |
| `sensitivity` | `low` · `low-med` · `med` · `med-high` · `high` | ✓ | קובע אם יש `safe` |

כותבים בעצמנו:

| שדה | סוג | חובה | נבנה ל… |
|---|---|---|---|
| `sub` | משפט | ✓ | שורת המשנה ב-hero |
| `format` | מחרוזת קצרה | ✓ | תגית ב-hero, למשל "זוגות, קבוצות ומליאה" |
| `question` | משפט | ✓ | שאלת השיעור (בכרטיס השיעור ובדף המרכז) |
| `takeaways` | 2–3 שורות | ✓ | "ייקחו איתם" |
| `prep` | רשימה (יכולה להיות ריקה) | ✓ | "צריך להכין" — רק מה שהבנייה לא מוסיפה לבד (סעיף "נגזר") |
| `safe` | רשימה של `{head, text}` | לפי `sensitivity` | תיבת "לפני השיעור" |
| `time.clock` | טקסט | ✓ | לחישת בדיקת השעון בסוף שלב התוכן האחרון |
| `time.short` | `{steps: [מזהים], text}` | ✓ | "אם חסר זמן גם לליבה — {text}. על כרטיס היציאה לא מוותרים." |
| `brain_break` | `{after?, signs, ideas, from}` | ✓ | `.tip` של הפסקת מוח; `ideas` = 2–3 × `{name, text}`; `from` = מזהה השלב שממנו לוקחים 3′; `after` (רשות) = מזהה שלב התוכן שאחריו — ברירת מחדל: זה שנגמר הכי קרוב לדקה 20 |
| `cover` | `{art, alt?, sub?}` | ✓ | שקף השער (שקף 1) |
| `steps` | רשימת שלבים | ✓ | |

## שלב

| שדה | סוג | חובה | הערה |
|---|---|---|---|
| `id` | `a-z0-9-` | ✓ | ייחודי; עוגן בדף ומזהה ל-`time.short`/`brain_break` |
| `title` | מחרוזת | ✓ | בהרחבה — בלי "אם נשאר זמן:" (נוסף לבד) |
| `kind` | `core` · `extension` · `messages` · `exit` | – | ברירת מחדל `core` |
| `minutes` | מספר | ✓ | |
| `practices` | רשימה | ✓ | ≥1 מ-11 הפרקטיקות, בכתיב המדויק |
| `spotlights` | רשימה | ✓ | ≥1 מ-5 הזרקורים |
| `summary` | שורה | ✓ | עמודת "מה עושים" בטבלת "השיעור במבט אחד" |
| `body` | רשימת בלוקים | ✓ | לפי סדר הקריאה |

סדר השלבים: כל שלבי `core` → `extension` → שלב `messages` אחד (אם יש מסרים במקור) → שלב `exit` אחד, אחרון.

## בלוקים (כל בלוק = מפתח אחד)

| בלוק | צורה | במערך |
|---|---|---|
| `p` | טקסט | פסקה למורה |
| `moves` | רשימה | צעדי המורה, ממוספרים |
| `list` | רשימה | תבליטים |
| `say` / `ask` | טקסט | "אומרים" / "שואלים" — אל הכיתה, ברבים |
| `whisper` | טקסט | "לעצמך" — הערה שקטה למורה |
| `tip` | טקסט | טיפ |
| `board` | טקסט, או רשימה (→ ממוספרת) | "על הלוח" |
| `timer` | `{sec, label}` | טיימר להפעלה + תווית |
| `task` | `{what, time, group, rules, plenary, help, challenge}` — הכול חובה | כרטיס "מה עושים?" + זמן · הרכב · כללים · במליאה, ומתחתיו שאלת עזר ושאלת אתגר |
| `ladder` | `{help, challenge}` | שאלת עזר ושאלת אתגר בלי כרטיס — למשימת כתיבה קצרה שההוראה שלה כבר על הלוח או המסך |
| `slide` | `{kicker?, title, sub?, points?, art, alt?, timer?, echo?, cue?}` | שקף במקום הזה. מהשקף השני בשלב — הפניה "שקף N" + `cue`. `echo: true` = מילות השקף כ"על המסך" |
| `video` | `{title, url, length?, before, watch, pause, predict, art, alt?}` | הכנה + שקף "לפני שצופים" עם `before` + על מה לשים לב + עצירה וחיזוי |
| `quote` | `{title?, text}` | ציטוט מילולי מהמקור (נבדק מול `src_text`) |
| `handout` | `{title, copies, items | text, verbatim?}` | דף להדפסה בתוך השלב (נכנס ל"צריך להכין"); `verbatim: true` כשהוא מהמקור כמו שהוא |
| `tracks` | בדיוק 2 × `{title, text, when, slides: [slide…]}` | שני מסלולים שווים, "מתאים כש:", שקפים לכל מסלול |
| `messages` | `{title?, items, ask, tip?, art, alt?}` — רק בשלב `messages` | המסרים מילה במילה + שקף שחושף אותם אחד־אחד + שאלה |
| `exit` | `{form, title, prompts, look_for, art, alt?, timer?}` — רק בשלב `exit` | `form: board` (ברירת מחדל) או `sticky` → "על הלוח"; `print` → כרטיס מודפס |

## איור (`art`) — בכל שקף

קנבס 620×540 ביחידות של הערכה (`assets/art/kit.svg`). **לפני שמרכיבים סצנה קוראים את `assets/art/art-guide.md`** — הקטלוג (שם, גודל טבעי, צבע ברירת מחדל של כל סמל) וכללי הקומפוזיציה. בכל מקום שיש `art` אפשר להוסיף `alt`: משפט קצר שמתאר מה רואים בתמונה (ברירת מחדל: הכותרת).

```yaml
art: heart                       # סמל אחד = המוקד: עד 390 יחידות, לכל היותר פי 1.6 מהגודל הטבעי
art:                             # סצנה: x,y = הפינה העליונה; בלי w — גודל טבעי (h נגזר מהיחס)
  - {use: kid-stand, x: 120, y: 260, color: teal}
  - {use: speech, x: 260, y: 40, w: 240}
  - {use: bulb, x: 328, y: 66, w: 104}           # סמל קטן בתוך בועה במקום מילים
  - {use: kid, x: 400, y: 470, color: orange}   # האסימון #kid: x,y = אמצע הגוף; scale רשות
  - text: אני                    # עד 3 מילים בתמונה, בגודל 30 ומעלה, בתוך בועה/לוח/שלט
    x: 310
    y: 300
    size: 40
art: {file: art/sun-circles.svg} # SVG ייעודי בתיקיית art/ של השיעור, viewBox="0 0 620 540"
```

- צבעים (`color`): `teal` · `orange` · `purple` · `moss` · `rose` · `gray` · `ink` (ו-`blue` רק לדגל), או hex מהפלטה. בלי `color` — צבע ברירת המחדל של הסמל.
- `flip: true` הופך מימין לשמאל.
- כל הסצנה עוברת את פילטר "מצויר ביד"; התוויות לא, כדי שייקראו מסוף הכיתה.
- המאמת מזהיר כשסצנה חורגת מכללי `art-guide.md`: יותר מ-5 סמלים, סמל מחוץ לפי 0.6–1.6 מהגודל הטבעי, מתחת לגודל המינימלי של סמל מפורט (`circle4`, `crowd`, `hands-help`, `school`, `red-line`, `face-*`), יחס w/h שונה מהסמל, יציאה מהשוליים (16), צבע מחוץ לפלטה, יותר מ-3 מילים או תווית קטנה מ-30.

## נגזר — לא כותבים ביד

- זמנים: שלבי התוכן מ-0′; הרחבות `+N′`; "חשוב לזכור" וכרטיס היציאה צמודים לצלצול (…–45′).
- טבלת "השיעור במבט אחד", מספור השקפים, כל הפניות השקפים (`שקף N` בכותרת וברגעי מעבר), שקף השער.
- "צריך להכין": שורת המצגת + ה-PDF, כל `handout`, כל סרטון, וחומר כרטיס היציאה.
- השורה "כתבי את שתי השאלות בפינת הלוח" מתחת לכל `task` ו-`ladder`; בדיקת השעון, "אם חסר זמן" והפסקת המוח — במקומם.
- "אם נשאר זמן:" בכותרות ההרחבות.

## דוגמה מקוצרת

```yaml
title: מקום בעולם
grade: 7
month: אוקטובר
section: חברות, סובלנות ומניעת אלימות (אוקטובר)
unit: למצוא מקום
unit_order: 1
unit_size: 2
src_text: sources/text/7/Makom_Baolam.md
sensitivity: med-high
sub: בכיתה חדשה, למצוא מקום לוקח זמן.
format: זוגות, קבוצות ומליאה
question: מה צריך כדי להרגיש שיש לי מקום — ואיך עושים מקום לכולם?
takeaways:
  - שייכות היא צורך של כולנו.
  - למצוא מקום לוקח זמן, וכולנו יכולים להשפיע.
prep:
  - טושים
safe:
  - head: תיאום עם היועצת
    text: >-
      ספרי לה מתי השיעור ועל מה, ובקשי שתהיה זמינה אחריו.
time:
  clock: >-
    כאן מסתכלים בשעון. נשארו 13 דקות ומעלה — ההרחבה; פחות — ישר ל״חשוב לזכור״.
  short:
    steps: [snowball]
    text: כדור השלג נשאר בזוגות בלבד
brain_break:
  signs: ראשים על השולחן, פיהוקים, תשובות של מילה אחת.
  ideas:
    - name: אף ואוזן
      text: יד שמאל על האוזן הימנית, יד ימין על האף, ובמחיאת כף מחליפים.
    - name: נשימת קופסה
      text: שואפים עד ארבע, עוצרים, נושפים עד ארבע. ארבעה סבבים.
  from: notes
cover:
  art: house
steps:
  - id: snowball
    title: כדור שלג מתגלגל
    minutes: 8
    practices:
      - הוצאה למשימה
    spotlights:
      - שיתופיות בלמידה
    summary: זוגות ואז רביעיות מחפשים דברים משותפים
    body:
      - moves:
          - הסבירי את שני הסבבים לפני שקמים.
          - הסתובבי בין הזוגות; דקה לפני המעבר — הודיעי.
      - slide:
          kicker: כדור שלג מתגלגל · בזוגות
          title: 10 משפטים ששומעים בבית
          art: pair
          timer: 180
      - task:
          what: >-
            מוצאים דברים משותפים בקבוצה שהולכת וגדלה.
          time: 3 דקות לכל סבב
          group: זוגות ← רביעיות
          rules: דף אחד לקבוצה
          plenary: נשארים ברביעיות
          help: מה אומרים אצלכם בבית בבוקר?
          challenge: מצאו משפט שכולכם שומעים — כל אחד במילים אחרות.
      - say: עצרו. כל זוג מצטרף לזוג שלידו.
  # … ועוד שלבי תוכן, הרחבה (kind: extension), שלב messages ושלב exit
```
