# הסכמה של lesson.yaml

קובץ אחד לכל שיעור: `lesson-lab/lessons/<slug>/lesson.yaml`. תוכן בלבד — בלי HTML ובלי עיצוב. המפתחות באנגלית, הערכים בעברית. מה כותבים בכל שדה — `style-guide.md`; כאן — הצורה. `validate.py` בודק הכול.

## כללי YAML (נשברים בלי זה)

- **טקסט עברי — רק בסגנון בלוק**: ערך אחרי `key: ` או אחרי `- `. אף פעם לא בתוך `[ … ]` או `{ … }` — סימן שאלה או פסיק בתוכם שוברים את הקובץ ("מה הקשר?"). רשימות כותבים בשורות, `- ערך` בכל שורה. `[ … ]` / `{ … }` מותרים רק למספרים ולמזהים (`{use: heart, x: 200, y: 150}`).
- ערך שמתחיל ב-`**`, או שיש בו `: ` (נקודתיים ורווח) או ` #` — כותבים כבלוק:
  ```yaml
  - p: >-
      **לפני השיעור:** פתחי את המצגת. על הלוח: שאלה אחת.
  ```
  `>-` מחבר שורות לפסקה אחת; `|` שומר על שורות (שבירת שורה במערך).
- זמן בסרטון ואורך סרטון — תמיד במירכאות: `at: "1:05"`, `length: "2:16"` (בלי מירכאות YAML קורא 65). גם `at: "?"`.
- הסימון היחיד בתוך טקסט: `**מודגש**` ושבירות שורה. בלי HTML.
- `say` / `ask`: בלי מירכאות מסביב — המערך מוסיף ״…״ בעצמו.

### תיבת `safe` (D24, D45)

| מתי | מה |
|---|---|
| `sensitivity`: `med` · `med-high` · `high` | חובה. ארבעה סעיפים (יועצת · מי עלול להיפגע · לא לוחצים לשתף · אם מישהו משתף פגיעה) |
| יש שלב עם `stance: true` (עמידה פומבית) — **בכל רמת רגישות, גם `low`** | חובה, ובה סעיף שהכותרת שלו **`עמידה מול הכיתה`**. ב-`low` מספיק הסעיף הזה לבד |
| `low-med` בלי עמידה | רק אם השיעור נוגע בעישון, אלכוהול, פגיעה, מיניות או היזכרות ברגע קשה |
| `low` בלי עמידה | בלי תיבה (שגיאה אם יש) |

### ציטוט מילולי (verbatim) — פטור מבדיקת הצורות המגדריות (D45, R9)

- **אוטומטית מילולי:** `messages.items`, `quote.text`, `handout` עם `verbatim: true`.
- **שקף:** `verbatim: true` = הכותרת, שורת המשנה וה-`points` הם ציטוט מהמקור (למשל היגדים של "מסכימומטר" עם "עייף/ה"); או רשימה: `verbatim: [points]`. ה-`kicker` תמיד שלך.
- כל שדה מילולי נבדק מול `src_text` (מילים, בלי פיסוק): לא נמצא → שגיאה. אז הסימון לא יכול להסתיר ניסוח שלך.
- **תיקון שקט (D23)** — טעות כתיב או שארית עריכה בציטוט — נרשם ב-`src_fixes`, והבדיקה מחילה אותו על המקור לפני ההשוואה:
  ```yaml
  src_fixes:
    - from: סיגירות          # בדיוק כמו במקור, כולל רווחים
      to: סיגריות
  ```
  `from` שלא נמצא במקור — שגיאה. תיקון שלא נרשם — אזהרת "כמעט מילה במילה".

### סרטון (`video`, D25, D44)

```yaml
- video:
    title: ניסוי הקונפורמיות של אש
    url: https://www.youtube.com/watch?v=l_YMx1cZX0A
    length: "2:16"            # רק אם אומת (בעמוד הסרטון); אחרת משמיטים
    before: מה תענו, אם כל מי שעונה לפניכם בוחר בקו אחר?
    watch: שימו לב לנבדק — איך הוא מגיב כשכל הקבוצה עונה לפניו.
    pauses:                   # לפחות אחת
      - at: "?"               # "דקה:שנייה", או "?" כשאי אפשר לאמת — והמורה מסמנת
        moment: הרגע שלפני תשובת הנבדק, אחרי שכל הקבוצה כבר טעתה.
        ask: מה הוא יענה עכשיו — ׳נכון׳ או ׳כמו כולם׳? מילה אחת, בלחישה לשכן.
    art: …
```

| שדה | מי רואה | איך |
|---|---|---|
| `before` | **הכיתה** — שקף "לפני שצופים" (עם כפתור "לסרטון") | גם במערך, כ"על המסך" |
| `watch` | **הכיתה שומעת** | במערך כ"אומרים" — משפט לתלמידים, ברבים ("שימו לב ל…") |
| `pauses[].at` | **המורה** | בשורת ההכנה ("סמני את נקודות העצירה: …") ובכותרת כל עצירה. `"?"` מוצג כ-[דקה:שנייה] מודגש למילוי |
| `pauses[].moment` | **המורה** | "עצירה ב־… — {moment}": איזה רגע בסרטון, כדי שתמצא ותסמן אותו. חובה כש-`at: "?"` |
| `pauses[].ask` | **הכיתה שומעת** | במערך כ"שואלים" — השאלה בעצירה |

בעצירה הסרטון על המסך, לא המצגת — לכן לעצירות אין שקף. ה-Think–Pair–Share שאחרי הצפייה הוא בלוקים רגילים (שקף, `ladder`). `watch` וכל `ask` של עצירה נספרים בין 2–3 ניסוחי המפתח של השלב.

### מסלולים (`tracks`, D11, D45)

כל מסלול הוא **תת־שלב מלא**: בלוקים משלו ותגיות משלו. מותרות כמה נקודות בחירה בשיעור (שלב `tracks` לכל אחת).

| שדה במסלול | חובה | הערה |
|---|---|---|
| `title` | ✓ | שם המסלול. האות (א׳/ב׳) נוספת לבד |
| `text` | ✓ | 1–2 שורות בכרטיס הבחירה |
| `when` | ✓ | "מתאים כש: …" |
| `practices` · `spotlights` | ✓ | ≥1 כל אחד — של המסלול הזה בלבד |
| `prep` | – | מה להכין רק למסלול הזה → "צריך להכין" כ"במסלול ״…״: …" |
| `body` | ✓ | בלוקים כמו בשלב (`slide`, `moves`, `task`, `ladder`, `say`, `quote`, `handout`, `video`…), עם **שקף אחד לפחות**. בלי `tracks`, `messages`, `exit` |

```yaml
- id: phone
  title: בחרי מסלול — בלי הטלפון
  minutes: 6
  summary: פרידה מהטלפון, באמת או בדמיון
  body:
    - tracks:
        - title: אני והנייד
          text: הטלפונים עוברים לסלסלה, וכל אחד כותב איזה דימוי עולה בו.
          when: מותר להחזיק טלפונים בשיעור, ואפשר לאסוף אותם בלי מאבק.
          practices:
            - כולם כותבים
          spotlights:
            - עניין ורלוונטיות
          prep:
            - סלסלה לטלפונים
          body:
            - slide: …
            - moves: …
            - ladder: …
            - ask: …
        - title: ניסוי המסכים הגדול
          …
    - say: שמענו כמה הטלפון חשוב לנו…     # משותף: מוצג תחת "בשני המסלולים"
```

במערך: כרטיסי הבחירה זה לצד זה (מסלול א׳ טורקיז, ב׳ סגול), ואחריהם כל מסלול כתת־פרק ממוסגר — כותרת, תגיות, הבלוקים שלו, הפניות לשקפים שלו. בלוקים אחרי ה-`tracks` נפתחים בכותרת "בשני המסלולים". במצגת: השקפים של מסלול א׳ ואז של ב׳ (המורה מדלגת על המסלול שלא בחרה; ההפניות במערך מקשרות ישר לשקף).

## איור (`art`) — בכל שקף

קנבס 620×540 ביחידות של הערכה (`assets/art/kit.svg`). **לפני שמרכיבים סצנה קוראים את `assets/art/art-guide.md`** — הקטלוג (שם, גודל טבעי, צבע ברירת מחדל של כל סמל) וכללי הקומפוזיציה. בכל מקום שיש `art` אפשר להוסיף `alt`: משפט קצר שמתאר מה רואים בתמונה (ברירת מחדל: הכותרת).

```yaml
art: heart                       # סמל אחד = המוקד: עד 390 יחידות, לכל היותר פי 1.6 מהגודל הטבעי
art:                             # סצנה: x,y = הפינה העליונה; בלי w — גודל טבעי (h נגזר מהיחס)
  - {use: kid-stand, x: 120, y: 260, color: teal}
  - {use: speech, x: 260, y: 40, w: 240}
  - {use: bulb, x: 328, y: 66, w: 104}           # פרט בתוך בועה: מותר עד פי 0.4
  - {use: red-line, x: 150, y: 224, w: 320, rotate: 90}   # סיבוב במעלות, סביב מרכז הסמל
  - {use: kid, x: 400, y: 470, color: orange}   # האסימון #kid: x,y = אמצע הגוף; scale רשות
  - text: אני                    # עד 3 מילים בתמונה, בגודל 30 ומעלה, בתוך בועה/לוח/שלט
    x: 310
    y: 300
    size: 40
art: {file: art/sun-circles.svg} # SVG ייעודי בתיקיית art/ של השיעור — מתכון ב-art-guide.md, "סצנה בקובץ"
```

- צבעים (`color`): `teal` · `orange` · `purple` · `moss` · `rose` · `gray` · `ink` (ו-`blue` רק לדגל), או hex מהפלטה. בלי `color` — צבע ברירת המחדל של הסמל.
- `flip: true` הופך מימין לשמאל; `rotate: מעלות` מסובב.
- כל הסצנה עוברת את פילטר "מצויר ביד"; התוויות לא, כדי שייקראו מסוף הכיתה.
- המאמת מזהיר כשסצנה חורגת מכללי `art-guide.md`: יותר מ-5 סמלים, סמל מחוץ לפי 0.6–1.6 מהגודל הטבעי (פרט בתוך בועה, לוח או מסך — מפי 0.4), מתחת לגודל המינימלי של סמל מפורט (`circle4`, `crowd`, `hands-help`, `school`, `red-line`, `face-*`), יחס w/h שונה מהסמל, יציאה מהשוליים (16), צבע מחוץ לפלטה, יותר מ-3 מילים או תווית קטנה מ-30 — גם בסצנת קובץ.

## נגזר — לא כותבים ביד

- זמנים: שלבי התוכן מ-0′; הרחבות `+N′`; "חשוב לזכור" וכרטיס היציאה צמודים לצלצול (…–45′).
- טבלת "השיעור במבט אחד", מספור השקפים, כל הפניות השקפים (`שקף N` בכותרת וברגעי מעבר), שקף השער, שורת שמות המסלולים בטבלה.
- שקפי המסרים — אחד לכל מסר, עם "חשוב לזכור · 2 מתוך 6"; גודל האות קטן לבד במסר ארוך.
- "צריך להכין": שורת המצגת + ה-PDF, כל `handout`, כל סרטון, חומר כרטיס היציאה, ו-`prep` של כל מסלול.
- השורה "כתבי את שתי השאלות בפינת הלוח" מתחת לכל `task` ו-`ladder`; בדיקת השעון, "אם חסר זמן" והפסקת המוח — במקומם; "בשני המסלולים" אחרי מסלולים.
- "אם נשאר זמן:" בכותרות ההרחבות.
